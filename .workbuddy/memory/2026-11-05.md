## UI 改造为 Cloudy 风格（分支 `ui/cloudy`）

背景：`mygo-qyin`（Lilt，QQ 音乐客户端，module `lilt`）与 `C:\Users\clover\Desktop\cloudy`（Cloudy，网易云客户端）
同源自分叉 `egoist/mygo-cloudmusic`，但 UI 层已各自演进。用户要求把 Lilt 的 UI 全面改成 Cloudy 样式，主色用 Cloudy 的红。

已完成（提交 8bd153c、93a547d）：
- 删除 `internal/app/radix.go`（Radix Sage/Green 调色板），新增 `palette_scale.go`：12 阶中性灰 `neutral()`、
  红色 accent 阶 `accent()`（oklch 0.6/0.21/24 与 0.66/0.2/22）、`warm()`、`veil()/shade()`、`ink/paper`。
- 全包 sed 重命名：radixSage/Gray→neutral、radixGreen/Red→accent、radixAmber→warm、radixWhite/Black→veil/shade、
  radixInk/Paper→ink/paper、radix*9→burst*。
- `paletteFor` 改为 Cloudy 精确取值（#ffffff/#f4f4f6/#1d1d1f、#141416/#1c1c1f/#f5f5f7、accent、cardShade）。
- 圆角统一为 Cloudy 语言：卡片/行 14、面板 20、大卡 26、小图 8、分段控件 14。
- 侧栏：去掉 main 左侧分隔线（只靠 tint 区分），选中行用 p.press、hover 用 p.hover。
- 搜索框改为 34 高胶囊（radius 17）。
- 新增 `ui_barglass.go`（照搬 Cloudy 的 `barGlass` shader 材质），播放栏可浮为玻璃胶囊。
- settings 新增 LiquidGlass / GlassClear / GlassBend / GlassPanels（默认 true/0.6/0.3/true），
  设置页新增「外观与玻璃」分组与 `glassSlider`。

踩坑记录：
- `surface` 与 `roundButton(... surface ...)` 参数重名 → 颜色函数改名 `neutral`。
- Go 文件是 CRLF，`gofmt -l` 会列出全部文件；**不要**跑 `gofmt -w`，会全库改行尾。
- 测试用 `ui.NewTester(a.view, w, h)` 渲染 PNG：`NM_FRAMES=<dir> go test ./internal/app -run TestCatalogFrames`。
  这类渲染里 `a.pal` 可能未初始化，控件内取色要用 `paletteFor(c.Theme())`。
- `TestTaskbarLyricsTwoLineContent` 在改动前就失败（字体行高 12.483959/12.516041），与本次无关。
